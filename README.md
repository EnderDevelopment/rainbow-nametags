# Rainbow Nametags

Customizable rainbow nametags for FiveM players

## Features

- Customizable player nametags with text
- Rainbow color effect for nametags

## Requirements

- FiveM server
- ESX framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start rainbow-nametags` to your server.cfg
4. Run the database.sql file to create the necessary table

## Usage

- Players can set their nametag text using the in-game command
- Nametags will automatically display in a rainbow color effect

## Configuration

- Adjust the nametag settings in the config.lua file
- Change the rainbow effect speed and intensity in the config.lua file
